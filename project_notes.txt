Project Name:
SEC Filing Intelligence Platform

GitHub Repository:
https://github.com/praneethkorada-1998/sec-10k-rag-assistant-v1

Project Summary:
Built a data-engineered RAG-based financial document intelligence platform using public SEC EDGAR 10-K filings. The platform retrieves current and historical filings, parses official SEC sections, creates OpenAI embeddings, stores vectors in ChromaDB, stores structured metadata in PostgreSQL, generates source-grounded answers, compares companies, and analyzes disclosure changes across filing years through Streamlit.

Problem Statement:
SEC 10-K filings are long, complex, and difficult to review manually. Analysts, business users, compliance teams, legal teams, and research teams often need quick answers from official filing sections such as Risk Factors, Cybersecurity, MD&A, Legal Proceedings, and Financial Statements. This project demonstrates how data engineering, GenAI, RAG, vector search, metadata filtering, and structured metadata storage can make SEC filings easier to search, compare, evaluate, and analyze.

Core Architecture:
- Streamlit provides the user interface.
- SEC EDGAR API provides public 10-K filing data.
- BeautifulSoup cleans and parses filing HTML.
- Formal SEC item parser extracts official filing sections.
- OpenAI embeddings convert filing chunks into vector representations.
- ChromaDB stores document chunks and embeddings for semantic search.
- PostgreSQL stores structured filing and chunk metadata.
- RAG layer generates source-grounded answers using retrieved filing chunks.
- GitHub Actions validates Python syntax and evaluation JSON.
- Docker and Docker Compose support repeatable local execution.

Key Features:
-Retrieves current and historical SEC 10-K filings from SEC EDGAR.
-Extracts official Items 1, 1A, 1C, 3, 7, 7A, and 8.
-Creates searchable chunks and OpenAI embeddings.
-Stores vectors in ChromaDB and metadata in PostgreSQL.
-Filters retrieval by ticker, SEC section, and filing accession.
-Generates source-grounded answers with supporting sources.
-Compares companies across selected SEC sections.
-Compares disclosures across filing years and highlights material changes.
-Displays indexed filing metadata and section-level chunk counts.
-Runs with Streamlit, Docker Compose, and GitHub Actions.

Important Local Commands:
cd C:\Users\prane\sec-10k-rag-assistant

Run Streamlit app:
py -m streamlit run app.py

Build Docker image:
docker build -t sec-filing-intelligence-platform:v7 .

Run Docker app:
docker run --rm -p 8501:8501 --env-file .env sec-filing-intelligence-platform:v7

Start PostgreSQL with Docker Compose:
docker compose up -d

Check running containers:
docker ps

Run retrieval evaluation:
py run_evaluation.py --ticker AAPL --top-k 10
